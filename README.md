## 🎨 About This Portfolio Repository

This repository hosts the source code for my interactive personal portfolio website.

### 🌟 Design Concept: *"The Tradesman's Job Docket"*
Unlike generic dark-mode developer templates, this portfolio is built around a warm, tactile analog theme:
* **Paper Textures:** Warm cream backgrounds (`#F4EEDD`, `#FCF8EC`) with subtle ledger line rules.
* **Brass Accents:** Warm gold accents (`#A8781B`) representing quality craft and brass fittings.
* **Rubber Stamp:** High-signal vermilion red (`#C43C2C`) for interactive CTA moments.
* **Rich Micro-Animations:** Scroll-triggered entrance animations, image pan containers for full-page website previews, interactive tab filtering, and responsive mobile layouts.

### 🛠️ Built With
* **Framework:** [React 19](https://react.dev/) + [Vite](https://vite.dev/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) + CSS Custom Properties
* **Icons:** [Lucide React](https://lucide.dev/)
* **Typography:** Google Fonts (*Outfit* for headings, *Inter* for body text)

### 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/khalidhussain-dev/KhalidPortfolio.git

# Navigate into project directory
cd KhalidPortfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
